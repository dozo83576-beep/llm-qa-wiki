# Дефекты навигации

Дефекты сквозных элементов умножаются на число страниц, поэтому дороже, чем кажутся.

## Пункт меню ведёт не туда

**Проявление.** Клик по пункту не открывает заявленный раздел: URL не меняется либо целевой секции на
странице нет.

**Причина.** Пустая или устаревшая ссылка, отсутствующий якорь, незавершённый раздел.

**Severity: `Major`.** Заявленный раздел недоступен; обходной путь есть, если раздел достижим иначе.
Повышается до `Critical`, если раздел не достижим никаким способом.

**Как проверить.** Зафиксировать URL до и после клика и наличие целевого элемента на странице. Одного
изменения URL недостаточно.

## Несуществующая страница отдаёт код 200

**Проявление.** Страница выглядит как 404, но сервер отвечает 200.

**Причина.** Обработка неизвестного адреса на клиенте без установки кода на сервере.

**Severity: `Minor`** для пользователя, но значимо для поисковой индексации: несуществующие адреса
попадают в индекс.

**Как проверить.** Открыть заведомо несуществующий адрес и посмотреть код ответа в панели сети.

## Логотип не ведёт на главную

**Проявление.** Клик по логотипу ничего не делает либо ведёт не на главную. На главной перезагружает
страницу вместо возврата к началу.

**Причина.** Логотип не оформлен ссылкой либо ссылка ведёт на служебный адрес.

**Severity: `Minor`.** Нарушает устойчивое ожидание пользователя, обходной путь очевиден.

**Как проверить.** Клик с внутренней страницы и с главной, прокрученной вниз.

## Битые ссылки в подвале

**Проявление.** Юридические документы, карта сайта или соцсети не открываются.

**Причина.** Подвал правится реже всего и проверяется последним.

**Severity: `Major`** для юридических документов — их наличие может быть обязательным.
`Minor` для соцсетей.

**Как проверить.** Обход всех ссылок с проверкой кода ответа, автоматизированно при большом числе.

## Текущий пункт меню остаётся активной ссылкой

**Проявление.** Клик по пункту страницы, на которой пользователь находится, перезагружает её.

**Причина.** Активное состояние не выделяется.

**Severity: `Trivial`.** Не мешает достижению цели.

**Как проверить.** На каждой странице проверить состояние соответствующего пункта меню.

## Потеря состояния при возврате назад

**Проявление.** Кнопка «Назад» из карточки товара возвращает в каталог со сброшенными фильтрами.

**Причина.** Состояние выборки не отражено в адресе страницы.

**Severity: `Major`.** Пользователь теряет подобранную выборку и уходит.

**Как проверить.** Применить фильтры, открыть карточку, вернуться назад.
