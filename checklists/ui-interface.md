# UI-интерфейс

Проверка соответствия интерфейса макетам, фирменному стилю и стандартам. Основан на исходном
чек-листе заказчика (`resources/source-checklists/`).

Формат: **критерий** — проверка — owner — severity.

## Соответствие макетам

- [ ] **Положение элементов и расстояния** соответствуют макету — расхождения описаны числами — QA — warn — [UI-тестирование](../docs/02-levels-and-types/ui-testing.md).
- [ ] **Состав элементов** на экране совпадает с макетом — QA — block.
- [ ] **Фирменный стиль соблюдён** — цвета, шрифты, логотип по брендбуку — QA — warn.

## Типографика

- [ ] **Текст читаем** на основном фоне и на плашках — QA — block.
- [ ] **Иерархия заголовков видна**: h1 крупнее h2 и далее — QA — warn.
- [ ] **Не более двух-трёх шрифтовых семейств** — QA — warn.
- [ ] **Заголовки не заканчиваются точкой**, капс не используется для основного текста — QA — warn.
- [ ] **Орфография проверена** — QA — warn.

## Состояния элементов

- [ ] **Реакция на наведение** у всех кликабельных элементов — подтверждена сравнением вычисленных стилей — QA — warn — [Паттерн](../patterns/ui/computed-style-hover-proof.md).
- [ ] **Видимый фокус** при навигации с клавиатуры — QA — block — [Доступность](../docs/11-security-accessibility/accessibility-wcag.md).
- [ ] **Курсор меняется на pointer** над кликабельным — QA — warn.
- [ ] **Отключённые элементы показаны, а не скрыты**, и объясняют причину — QA — warn.
- [ ] **Посещённые ссылки** отличаются визуально — QA — warn.
- [ ] **Вся область кнопки кликабельна**, не только надпись — QA — warn.
- [ ] **Реакция на наведение видна на экране**, а не только в вычисленных стилях — подтверждена попиксельным сравнением области — QA — warn — [Паттерн](../patterns/ui/pixel-diff-hover-proof.md).
- [ ] **Всплывающее по наведению содержимое закрывается клавишей `Esc`** без перемещения курсора — WCAG 2.2, 1.4.13 — QA — warn.
- [ ] **Выпадающий блок раскрывается и при получении фокуса с клавиатуры**, его пункты попадают в порядок обхода `Tab` — QA — block — [Таксономия](../bug-taxonomy/ui-states.md).

## Адаптивность

- [ ] **Проверены все ширины из матрицы** — QA — block — [Адаптивность](../docs/06-web-testing/cross-browser-responsive.md).
- [ ] **Нет горизонтальной прокрутки** ни на одной ширине — QA — block.
- [ ] **Альбомная ориентация** проверена на мобильных — QA — warn.
- [ ] **Элементы не наезжают и не обрезаются** — QA — block.
- [ ] **Кликабельные элементы достаточного размера** для касания пальцем — QA — warn.

## Поля и стандартные элементы

- [ ] **Поведение поля при длинном значении** — текст не выезжает за границы — QA — warn.
- [ ] **Чекбоксы, радиокнопки, селекты** выглядят и работают единообразно — QA — warn.
- [ ] **Поля специального формата** (карта, телефон, дата) имеют маску или подсказку — QA — warn.

## Элементы информирования

- [ ] **Сообщения об ошибках** размещены рядом с проблемным полем — QA — warn.
- [ ] **Уведомления и подсказки** единообразны по виду и месту — QA — warn.
- [ ] **Индикатор загрузки** появляется при длительных операциях — QA — warn.

## Соответствие стандартам платформы

- [ ] **Гайдлайны платформы соблюдены** для мобильных приложений — QA — warn.

## Stop conditions

Невыполненный `block` останавливает передачу. Отсутствие видимого фокуса и горизонтальная прокрутка
на мобильном разрешении блокируют сдачу публичного сайта.
