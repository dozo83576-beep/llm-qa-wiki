# Функциональное тестирование веба

Базовый набор проверок для любого сайта с формами. Основан на исходном чек-листе заказчика
(`resources/source-checklists/`), дополнен техниками тест-дизайна.

Формат: **критерий** — проверка — owner — severity (`block` останавливает сдачу, `warn` фиксируется в
отчёте).

## Регистрация

- [ ] **Регистрация с валидными данными** — создаётся аккаунт, приходит письмо — QA — block — [Формы](../docs/06-web-testing/forms-and-validation.md).
- [ ] **Повторная регистрация существующего пользователя** — отклоняется с понятным сообщением — QA — block.
- [ ] **Заблокированный пользователь не проходит повторную регистрацию** — QA — warn.
- [ ] **Валидация всех обязательных полей** — длина, символы, обязательность — QA — block — [Границы](../docs/03-test-design/boundary-value-analysis.md).

## Авторизация

- [ ] **Верный логин и пароль** — вход выполняется — QA — block.
- [ ] **Несуществующий логин** — отказ, без раскрытия факта существования учётной записи — QA — block.
- [ ] **Существующий логин, неверный пароль** — отказ с понятным сообщением — QA — block.
- [ ] **Логин без пароля и пароль без логина** — отклоняются — QA — block.
- [ ] **Заблокированный пользователь** — отказ с указанием причины — QA — warn.
- [ ] **Восстановление и смена пароля** — работают до конца, включая письмо — QA — block.

## Поля ввода

- [ ] **Минимальная и максимальная длина, на единицу за пределом** — QA — block — [Границы](../docs/03-test-design/boundary-value-analysis.md).
- [ ] **Обязательные поля помечены визуально** — QA — warn.
- [ ] **Незаполненное необязательное поле не вызывает ошибку** — QA — block.
- [ ] **Числовые поля не принимают буквы**, сообщение об ошибке конкретно — QA — block.
- [ ] **Дробные значения** — проверены `1.1` и `1,1` — QA — warn.
- [ ] **Отрицательные значения** там, где не имеют смысла, отклоняются — QA — warn.
- [ ] **Спецсимволы во всех полях ввода** — обрабатываются, не ломают страницу — QA — block.
- [ ] **Пробелы в начале и конце** обрезаются; строка из одних пробелов не считается заполненной — QA — warn.
- [ ] **Текст не выходит за границы поля** и не обрезается многоточием — QA — warn.
- [ ] **Серверная валидация** работает при обходе клиентской — QA — block — [Формы](../docs/06-web-testing/forms-and-validation.md).

## Отправка формы

- [ ] **Форма доходит до адресата** — проверено в согласованном канале, а не по надписи «Спасибо» — QA — block.
- [ ] **Двойной клик по кнопке отправки** не создаёт дубль — QA — block.
- [ ] **Введённые данные сохраняются** при ошибке валидации — QA — warn.
- [ ] **Код ответа сервера** зафиксирован для каждой формы — QA — block — [DevTools](../docs/06-web-testing/devtools-console-network.md).

## Поиск

- [ ] **Запрос с результатами и без результатов** — корректное сообщение при пустой выдаче — QA — block.
- [ ] **Пустой запрос** — поведение определено — QA — warn.
- [ ] **Спецсимволы и эмодзи** не ломают поиск — QA — warn.

## Сообщения и всплывающие подсказки

- [ ] **Сообщения об ошибках называют поле и правило** — QA — warn.
- [ ] **Подтверждения появляются** для операций обновления и удаления — QA — warn.

## Дополнительно

- [ ] **Все кнопки выполняют заявленное действие** — QA — block.
- [ ] **Наличие favicon** — QA — warn.
- [ ] **Обработка ошибок**: 404 отдаёт код 404, ошибка сервера обработана, тайм-аут сообщается — QA — block.
- [ ] **Загрузка и скачивание файлов** работают; файлы уходят на сервер только после нажатия кнопки — QA — block.
- [ ] **Загруженные документы открываются** корректно — QA — warn.
- [ ] **Кэш, cookie и сессии** — проверены очистка кэша и удаление cookie во время визита и после — QA — warn — [Cookie](../docs/06-web-testing/cookies-sessions-cache.md).
- [ ] **Консоль без ошибок** на ключевых страницах — QA — block.
- [ ] **Все стили и изображения загружаются** — нет 404 на ресурсах — QA — block.

## Stop conditions

Любой невыполненный `block` останавливает передачу заказчику. Форма, не доходящая до адресата, и
ошибка сервера на пользовательском сценарии — безусловные блокеры независимо от остального.
