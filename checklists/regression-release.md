# Регресс перед релизом

Гейт повторного прогона после изменений. Срабатывает перед выкладкой и после пакета исправлений.

Формат: **критерий** — проверка — owner — severity.

## Вход

- [ ] **Получен список изменений** — что правили, какие дефекты исправлены, что обновляли — QA — block — [Playbook](../docs/13-playbooks/regression-before-release.md).
- [ ] **Известна версия сборки**, на которой ведётся прогон — QA — block.
- [ ] **Тестовая среда соответствует** продакшену по существенным настройкам — QA — warn.

## Smoke

- [ ] **Главная открывается**, консоль без ошибок — QA — block.
- [ ] **Авторизация работает** — QA — block.
- [ ] **Ключевой сценарий проходится** целиком — QA — block.
- [ ] **Smoke укладывается в 15 минут** — QA — warn — [Smoke и регресс](../docs/02-levels-and-types/smoke-regression-retest.md).

## Ретест исправлений

- [ ] **Каждый исправленный дефект проверен по шагам из баг-репорта** — QA — block — [Жизненный цикл](../docs/05-defect-management/defect-lifecycle.md).
- [ ] **Ретест выполнен на той сборке**, где заявлено исправление — QA — block.
- [ ] **Проверена область вокруг каждого исправления** — QA — block.
- [ ] **Возвращённые дефекты переоткрыты**, а не заведены заново — QA — warn.

## Зона изменений

- [ ] **Изменённые области проверены** полностью — QA — block.
- [ ] **Зависимые области проверены** — QA — block.
- [ ] **Обновлённые библиотеки и модули** проверены на затронутой функциональности — QA — warn.

## Сквозные элементы

- [ ] **Шапка, подвал, меню** работают на всех типах страниц — QA — block — [Навигация](../docs/06-web-testing/navigation-and-links.md).
- [ ] **Авторизация и выход** — QA — block.
- [ ] **Формы обратной связи** доходят до адресата — QA — block.

## Критичные сценарии

- [ ] **Оплата или отправка заявки** пройдена целиком независимо от зоны правок — QA — block.
- [ ] **Регистрация** пройдена целиком — QA — block.
- [ ] **Места прошлых дефектов** проверены — QA — warn — [Принципы](../docs/01-fundamentals/testing-principles.md).

## Совместимость

- [ ] **Smoke на остальных браузерах** из матрицы — QA — block.
- [ ] **Ключевой сценарий на мобильном разрешении** — QA — block.

## Выход

- [ ] **Все `block` выполнены** — QA — block.
- [ ] **Новые дефекты оформлены** с доказательствами — QA — block.
- [ ] **Регрессионный набор пополнен** проверками на ранее пропущенные дефекты — QA — warn.
- [ ] **Отчёт содержит оценку относительно exit criteria** — QA — block — [Отчёт](../docs/04-documentation/test-summary-report.md).

## Stop conditions

Провал smoke останавливает прогон целиком: сборка возвращается, дальше не тестируем. Любой
невыполненный `block` откладывает релиз. Решение о выпуске вопреки невыполненным критериям принимает
владелец продукта и фиксирует письменно.
