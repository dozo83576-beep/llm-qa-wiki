# Доступность

Проверка соответствия WCAG уровня AA. Автоматические инструменты покрывают меньшую часть — основное
проверяется вручную.

Формат: **критерий** — проверка — owner — severity.

## Клавиатура

- [ ] **Весь ключевой сценарий проходится без мыши** — QA — block — [WCAG](../docs/11-security-accessibility/accessibility-wcag.md).
- [ ] **Фокус виден всегда** и не теряется — QA — block.
- [ ] **Порядок обхода соответствует визуальному** — QA — warn.
- [ ] **Нет ловушек фокуса** — из модального окна можно выйти — QA — block.
- [ ] **Модальное окно забирает фокус** при открытии и возвращает при закрытии — QA — warn.
- [ ] **Всё кликабельное мышью доступно с клавиатуры** — QA — block.
- [ ] **Есть возможность пропустить навигацию** — QA — warn.

## Контраст и цвет

- [ ] **Обычный текст не менее 4.5:1** — замер инструментом — QA — block.
- [ ] **Текст поверх картинки или градиента** — контраст замерен по пикселям отрисованной страницы, а не по CSS-декларации — QA — block — [Паттерн](../patterns/ui/pixel-contrast-on-image-background.md).
- [ ] **Крупный текст и интерактивные элементы не менее 3:1** — QA — block.
- [ ] **Состояния hover и focus** проверены на контраст отдельно — QA — warn.
- [ ] **Цвет не единственный носитель смысла** — статус не только красным или зелёным — QA — block.

## Текст и структура

- [ ] **Один h1 на страницу**, уровни заголовков без пропусков — QA — warn.
- [ ] **Язык страницы объявлен** — QA — warn.
- [ ] **Текст масштабируется до 200%** без потери содержимого — QA — warn.

## Изображения и медиа

- [ ] **Содержательные изображения имеют осмысленное описание** — не имя файла — QA — block.
- [ ] **Декоративные изображения имеют пустое описание** — QA — warn.
- [ ] **Видео имеет субтитры**, если содержит речь — QA — warn.
- [ ] **Автовоспроизведение можно остановить** — QA — block.
- [ ] **Анимация уважает системную настройку** уменьшения движения — QA — warn.

## Формы

- [ ] **У каждого поля есть связанная подпись**, а не только подсказка внутри — QA — block.
- [ ] **Ошибка сообщается текстом**, а не только цветом рамки — QA — block.
- [ ] **Обязательность обозначена** не только цветом — QA — warn.
- [ ] **Сообщение об ошибке связано с полем** программно — QA — warn.

## Проверка инструментами

- [ ] **Автоматический аудит пройден**, нарушения разобраны — QA — warn.
- [ ] **Ключевой сценарий проверен со скринридером** — QA — warn.
- [ ] **Элементы находятся по роли и доступному имени** — косвенная проверка через автотесты — QA — warn — [Локаторы](../docs/09-automation/locators-and-page-objects.md).

## Stop conditions

Невыполненный `block` останавливает сдачу проекта, для которого доступность заявлена или обязательна
по требованиям. Для остальных проектов невыполненные `block` фиксируются в отчёте как риск, а решение
принимает заказчик.

Каждое замечание содержит номер критерия WCAG и замеренное значение — иначе оно неопровержимо и
нечинимо.
