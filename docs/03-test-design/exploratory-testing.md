# Исследовательское тестирование

Одновременное изучение продукта, проектирование проверок и их выполнение. Не «потыкать наугад»:
дисциплина обеспечивается сессиями с явной целью и записью хода.

## Когда использовать

- Требований нет или они устарели — типичная ситуация внешнего заказа.
- Мало времени: сессия даёт результат быстрее, чем построение набора кейсов.
- Продукт незнаком: разведка перед составлением тест-плана.
- После формального прогона — добрать то, что не покрылось.

## Когда не использовать

- Когда нужен воспроизводимый регрессионный набор. Результат сессии не повторяется другим человеком
  дословно.
- Как единственный вид работы на заказе с приёмкой по критериям: заказчику нужен явный статус по
  каждому критерию.

## Как это делается

Работа ведётся сессиями. Одна сессия — 60–90 минут, одна цель.

**Устав сессии** формулируется до начала:

> Исследовать оформление заказа с целью найти дефекты валидации и потери данных, используя ввод
> граничных значений и прерывание сценария.

**Во время сессии** записываются: что проверено, что найдено, что показалось подозрительным, какие
вопросы возникли. Запись ведётся по ходу, а не по памяти после.

**После сессии**: находки превращаются в дефекты с воспроизводимыми шагами, подозрительное — в
кейсы для следующего прогона, вопросы — в список к заказчику.

Тайминг разумно делить: примерно две трети на исследование, треть на оформление находок. Оформление
после сессии, а не «когда-нибудь потом» — детали забываются за час.

## Практика на заказе без ТЗ

Порядок, который работает:

1. Сессия-разведка: пройти основные сценарии как пользователь, составить карту разделов.
2. Зафиксировать оракул: чем будем считать «правильно», см.
   [оракул и границы](../01-fundamentals/test-oracle-and-limits.md).
3. Сессии по областям: формы, каталог, личный кабинет.
4. По итогам — формальный набор кейсов на найденные критичные области.

## Частые ошибки

- Сессия без устава: превращается в бесцельное кликанье, отчитаться нечем.
- Запись после сессии по памяти: половина находок теряется, шаги воспроизведения неточны.
- Отсутствие тайм-бокса: три часа в одной области при непроверенных остальных.
- Оформление находок словами «странно себя ведёт» без шагов.

## Проверка

- У каждой сессии есть записанный устав и длительность.
- Есть журнал сессии: что проверено и что найдено.
- Каждая находка оформлена дефектом с воспроизводимыми шагами.
- Покрытые области отмечены на карте, непокрытые видны.
