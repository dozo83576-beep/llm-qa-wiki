# QA лендинга

Маршрут для сайта-визитки, одностраничника или промо-страницы. Объём небольшой, поэтому важно не
распылиться: ценность лендинга — в целевом действии, туда и идёт основное внимание.

## Когда использовать

- Одностраничный сайт или сайт до десяти страниц.
- Основная цель — заявка, звонок, подписка.
- Каталога и личного кабинета нет.

## Когда не использовать

- Есть каталог с фильтрами и корзина — нужен [маршрут магазина](ecommerce-qa.md).
- Есть личный кабинет с ролями — добавляются проверки разграничения доступа.

## Шаги

**1. Приём.** Зафиксировать URL, окружение, целевое действие, матрицу браузеров и разрешений.
Уточнить, куда должны приходить заявки, и получить доступ к этому каналу — без него проверить форму
невозможно.

**2. Первый проход с открытыми DevTools.** Пройти страницу целиком как пользователь. Собрать ошибки
консоли и коды ответов. См. [DevTools](../06-web-testing/devtools-console-network.md).

**3. Формы — основной объём.** Для каждой формы:
границы и классы значений, обязательность, двойная отправка, сохранность введённого при ошибке,
серверная валидация в обход клиентской, **фактическая доставка заявки**. См.
[формы](../06-web-testing/forms-and-validation.md).

**4. Навигация и якоря.** Каждый пункт меню и каждая кнопка ведут туда, куда обещают. Логотип
возвращает к началу. Кнопка «Наверх» работает. Подвал: юридические документы открываются, ссылки на
соцсети рабочие.

**5. Состояния элементов.** Реакция на наведение и фокус у всех кликабельных элементов. Типовой
дефект лендингов — кнопка выглядит кликабельной, но не реагирует, см.
[паттерн](../../patterns/ui/computed-style-hover-proof.md).

**6. Адаптивность.** Ширины 360, 414, 768, 1280, 1440 px. Отсутствие горизонтальной прокрутки.
Целевое действие достижимо без долгой прокрутки. Альбомная ориентация.

**7. UX-проход.** [Чек-лист UX](../../checklists/ux-experience.md): понятность за 3 секунды, CTA,
контакты, favicon, обработка 404.

**8. Скорость.** Замер на профиле мобильной сети с холодным кэшем. Замечания с числами, см.
[метрики](../10-performance/metrics.md).

**9. Отчёт.** Сборка XLSX и прогон валидатора.

## Частые ошибки

- Проверка формы по надписи «Спасибо» без контроля доставки.
- Пропуск подвала и юридических страниц.
- Адаптивность проверена перетаскиванием края окна вместо фиксированных ширин.
- Замер скорости на офисном Wi-Fi.

## Проверка

- Каждая форма проверена до фактической доставки в согласованный канал.
- Проверены все ширины из матрицы, горизонтальной прокрутки нет.
- Консоль чиста на всех страницах.
- Проверен несуществующий URL.
- Отчёт прошёл валидатор.
