# Шаблон баг-репорта

Заготовка для `_qa-defects.md`. Поля соответствуют колонкам листа `Bug Reports` в
[формате отчёта](xlsx-test-management.md).

## Когда использовать

- Фаза `qa-defects` для каждого подтверждённого расхождения.

## Когда не использовать

- Вкусовое замечание без опоры на норму — оно идёт в раздел рекомендаций.
- Неопределённое поведение — сначала вопрос заказчику.

## Шаблон

```markdown
### BR-0NN — <суть в одной строке>

- **Severity:** Critical | Major | Minor | Trivial — <обоснование по таксономии>
- **Priority:** High | Medium | Low
- **Окружение:** <браузер, версия, ОС, разрешение>
- **Доказательство:** <ссылка>
- **Дата:** YYYY-MM-DD

**Проявления**

| Кейс | Предусловия | Шаг с ошибкой | Ожидалось | Фактически |
|---|---|---|---|---|
| TC-0NN | <...> | <...> | <...> | <...> |
```

Таблица «Проявления» — это и есть построчная раскладка дефекта: каждая строка станет строкой на листе
`Bug Reports`, `Bug ID` и `Title` попадут только в первую.

## Заполненный пример

```markdown
### BR-001 — Нет hover-эффекта у логотипа и пунктов меню шапки

- **Severity:** Minor — элемент выглядит кликабельным, но не подтверждает это; цель достижима
- **Priority:** Medium
- **Окружение:** Chrome 150, Windows 10, 1440×900
- **Доказательство:** https://example.test/evidence/br-001
- **Дата:** 2026-07-30

**Проявления**

| Кейс | Предусловия | Шаг с ошибкой | Ожидалось | Фактически |
|---|---|---|---|---|
| TC-001 | Открыта главная, курсор вне шапки | Навести курсор на логотип | Заметная визуальная реакция | Цвет, фон, рамка не изменяются |
| TC-003 | То же | Навести курсор на «Главная» | То же | То же |
```

## Правила

- Заголовок называет конкретный элемент и конкретную проблему.
- Фактический результат описывает наблюдаемое, а не предполагаемую причину.
- Объединять проявления можно только при одной причине и одной правке; иначе — разные дефекты.
- Доказательство — ссылкой, не вложением.
- Тон нейтральный.

## Частые ошибки

- Заголовок «не работает меню».
- Гипотеза о причине вместо наблюдения.
- Объединение независимых дефектов.
- Отсутствие окружения — дефект вернётся как «не воспроизвелось».
- Отсутствие связи с кейсом — валидатор отчёта отклонит файл.

## Проверка

- Дефект воспроизведён автором по собственным шагам на чистой сессии.
- Каждое проявление связано с кейсом.
- Severity обоснована по [таксономии](../../bug-taxonomy/index.md).
- Доказательство открывается по ссылке.
