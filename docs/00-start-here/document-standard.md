# Стандарт документа

Контракт, которому подчиняется каждый файл вики. Нарушение ловит `tools/wiki-audit.ps1` (блокирует)
и `tools/wiki-quality.ps1` (предупреждает).

## Обязательный front matter

Шесть полей, все проверяются CI:

- `title` — строка.
- `category` — из словаря: `start`, `navigation`, `fundamentals`, `test-design`, `documentation`,
  `defects`, `web`, `mobile`, `api`, `automation`, `performance`, `security`, `accessibility`,
  `process`, `playbook`, `template`, `checklist`, `pattern`, `case-study`, `lesson`, `maintenance`,
  `prompt`, `resource`, `bug-taxonomy`.
- `updated` — `YYYY-MM-DD`, дата содержательного изменения.
- `status` — `active`, `archived`, `draft`, `redirect`, `validated`.
- `tags` — 2–6 тегов. Пустой `[]` — ошибка CI: документ становится невидим для поиска по тегам.
- `source_priority` — `internal`, `official-docs`, `vendor-docs`, `mixed`, `community`,
  `external-proposal`.

Опциональные: `reviewed` (перечитал, но не правил — честно гасит предупреждение об устаревшей дате),
`area` и `test_level` в паттернах, `date` и `severity` в кейсах и уроках.

Теги не дублируют `category`: категория говорит, что это за документ, теги — о чём он.

## Структура

Обязательный скелет для документов в `docs/01-*` … `docs/14-*`:

1. `# Заголовок` и один абзац назначения.
2. `## Когда использовать`
3. `## Когда не использовать`
4. `## Как это делается` (или `## Правила`, `## Практика`)
5. `## Частые ошибки`
6. `## Проверка` — чем подтверждается, что применено верно.
7. `## Источники`

CI допускает пропуск одной секции из шести — на синонимы и структурные вариации. Пропуск двух и
более даёт предупреждение.

## Стиль

- Списки, а не абзацы. Абзац длиннее двух строк — повод разбить.
- Ориентир объёма — 1500–3000 символов. Короче 1200 — предупреждение CI.
- Формулировки проверяемые: не «форма должна работать быстро», а «ответ формы < 2 с при
  100 одновременных отправках».
- Русский язык. Английские термины (smoke, regression, severity) не переводятся — они в отчётах.
- Элементы интерфейса — в «ёлочках»: кнопка «Отправить».

## Частые ошибки

- Пересказ теории вместо инструкции. Документ, который нельзя применить без автора, не готов.
- Копирование чужих материалов целиком. Допустим собственный конспект, ссылка и дата проверки.
- `source_priority: internal` при ссылке на официальную документацию — это `mixed`.
- Маркеры `TODO`, `TBD`, `FIXME` запрещены и блокируют CI. Незавершённое либо дописывается, либо не
  коммитится.

## Проверка

Definition of Done документа:

- Есть front matter со всеми шестью полями.
- Есть практическое решение или чек-лист, а не только определения.
- Каждое внешнее утверждение подкреплено ссылкой с датой проверки.
- Документ применим в проекте без дополнительных объяснений автора.

```
pwsh tools/ci-local.ps1
```
