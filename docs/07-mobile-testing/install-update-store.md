# Установка, обновление, стор

Переносимость приложения: как оно ставится, обновляется и удаляется. Область, которую пропускают
чаще всего, потому что тестировщик обычно работает на уже установленной сборке.

## Когда использовать

- Перед каждым релизом в стор.
- При изменении структуры локальных данных.
- При повышении минимальной версии ОС.

## Когда не использовать

- Промежуточная сборка для проверки одной функции.

## Установка

- Чистая установка на устройство, где приложения не было.
- Первый запуск: онбординг, запрос разрешений, стартовый экран загрузки.
- Установка при нехватке места.
- Запуск на минимальной поддерживаемой версии ОС.
- Приложение работает сразу после установки, без перезапуска устройства.

## Обновление

Ключевая проверка мобильного релиза — **обновление поверх предыдущей версии, а не чистая установка**.

- Данные пользователя сохраняются: авторизация, настройки, черновики, кэш.
- Миграция локальной базы проходит без потери данных.
- Обновление с версии на две-три назад, а не только с последней: пользователи обновляются
  нерегулярно.
- Старая версия приложения продолжает работать с новым сервером либо честно требует обновления, а не
  падает.
- Онбординг не показывается повторно тем, кто его уже прошёл.

Отдельно: приложение на старой версии должно получить понятное сообщение «обновите приложение», если
сервер перестал поддерживать её протокол. Молчаливое падение — дефект `Critical`.

## Удаление и переустановка

- Удаление проходит полностью, не оставляя работающих служб.
- Переустановка даёт состояние чистой установки, а не остатки прошлой.
- Данные, которые должны сохраниться в облаке, восстанавливаются после входа.

## Подготовка к стору

- Версия и номер сборки увеличены.
- Иконка и заставка корректны на всех плотностях экрана.
- Разрешения в манифесте соответствуют фактически используемым: лишние вызывают отказ в публикации.
- Политика конфиденциальности доступна по ссылке из приложения.
- Приложение не падает на первом запуске — основная причина отклонения ревью.

## Частые ошибки

- Тестирование только чистой установки: миграция данных не проверяется вообще.
- Обновление только с последней версии.
- Пропуск проверки старого клиента с новым сервером.
- Проверка на одном флагманском устройстве: слабое устройство даёт другие дефекты.

## Проверка

- Проверено обновление поверх минимум двух предыдущих версий.
- После обновления подтверждена сохранность пользовательских данных.
- Проверено поведение старой версии клиента с новым сервером.
- Проверена чистая установка на минимальной поддерживаемой ОС.
