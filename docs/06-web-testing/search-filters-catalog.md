# Поиск, фильтры, каталог

Выборка данных: поиск, фильтрация, сортировка, постраничная навигация. Область с комбинаторным
взрывом, поэтому проверяется [попарным методом](../03-test-design/pairwise-testing.md), а не полным
перебором.

## Когда использовать

- Интернет-магазин, каталог услуг, база объектов, блог с рубриками.

## Когда не использовать

- Сайт из пяти страниц без выборки.

## Поиск

- Запрос с результатами; запрос без результатов и корректное сообщение вместо пустого экрана.
- Пустой запрос: либо блокируется, либо показывает всё — важно, чтобы поведение было определено.
- Спецсимволы, эмодзи, очень длинная строка.
- Регистр: «Обувь» и «обувь» дают одинаковый результат.
- Опечатка: исправляется или предлагается исправление.
- Раскладка клавиатуры: `j,tym` вместо «обувь».
- Поиск один на сайт, запускается кнопкой и по Enter.
- В выдаче видно количество результатов и тип сортировки.

## Фильтры

- Комбинация с выдачей и комбинация без выдачи.
- Сброс фильтров возвращает полный список.
- Ползунок цены: перетаскивание обеих границ, крайние положения.
- Поля «от» и «до»: «от» больше «до», отрицательные значения, буквы.
- Селекты, радиокнопки, чекбоксы: множественный выбор, снятие последнего выбранного.
- Счётчик найденного обновляется вместе с выдачей.
- Состояние фильтров сохраняется при переходе в карточку и возврате назад.
- Фильтры отражаются в URL — иначе ссылку на выборку нельзя передать.

## Сортировка

- По возрастанию, по убыванию, по новизне.
- Сортировка сохраняется при смене страницы.
- Сортировка по цене учитывает скидочную цену, а не базовую, если на витрине показана скидочная.
- Товары без значения поля сортировки не исчезают из выдачи.

## Постраничная навигация

- Ровно одна страница элементов; страница плюс один элемент; последняя страница.
- Переход на несуществующий номер страницы.
- Число элементов на странице меняется и сохраняется.
- Прямая ссылка на страницу N открывает именно её.

## Частые ошибки

- Проверка фильтров только на комбинациях с результатами. Пустая выдача — отдельный сценарий, где
  чаще всего ломается вёрстка.
- Пропуск сохранения состояния при возврате назад: пользователь теряет подобранную выборку.
- Игнорирование производительности: фильтр с широким диапазоном отдаёт тысячи записей и вешает
  страницу, см. [производительность](../10-performance/index.md).
- Проверка сортировки на первой странице без перехода дальше.

## Проверка

- Комбинации фильтров покрыты попарным набором, включая пустую выдачу.
- Границы диапазонов проверены, включая «от» больше «до».
- Состояние выборки сохраняется в URL и при возврате назад.
- Постраничная навигация проверена на границах.
- Замерено время отклика на самой широкой выборке.
