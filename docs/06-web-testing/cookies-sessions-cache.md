# Cookie, сессии и кэш

Состояние, которое живёт между запросами и визитами. Источник дефектов, которые не воспроизводятся у
разработчика: у него состояние другое.

## Когда использовать

- Есть авторизация, корзина, персонализация, баннер согласия.
- Дефект не воспроизводится у разработчика, но стабилен у пользователя.

## Когда не использовать

- Полностью статический сайт без состояния и без баннера согласия.

## Что проверять

**Сессия.**

- Вход, закрытие браузера, повторное открытие: сессия сохранилась или нет — согласно заявленному
  поведению.
- Истечение сессии: действие после долгого бездействия даёт понятное сообщение и возврат к входу, а
  не ошибку сервера и не потерю введённых данных.
- Выход завершает сессию: возврат по кнопке «Назад» не показывает личные данные.
- Одновременная работа в двух вкладках: выход в одной корректно отражается в другой.
- Одновременный вход с двух устройств — согласно заявленному поведению.

**Cookie.**

- Удаление cookie во время работы на сайте: поведение предсказуемо.
- Удаление cookie после визита: возврат на сайт не ломает страницу.
- Приватный режим: сайт работает, состояние не сохраняется между окнами.
- Блокировка сторонних cookie: базовая функциональность сохраняется.

**Баннер согласия.**

- Отказ от необязательных cookie действительно отключает соответствующие скрипты.
- Выбор запоминается и баннер не появляется снова.
- До согласия аналитика и маркетинговые скрипты не грузятся.

**Кэш.**

- После обновления сайта пользователь со старым кэшем получает новую версию, а не смесь старых
  стилей с новой разметкой.
- Жёсткая перезагрузка не ломает страницу.
- Данные, которые не должны кэшироваться, не кэшируются: страницы личного кабинета.

**Корзина без авторизации.** Сохраняется между визитами. При входе объединяется с корзиной аккаунта,
а не затирает её.

## Частые ошибки

- Тестирование всегда в одном окне с накопленным состоянием: дефекты первого визита не находятся.
- Пропуск сценария истечения сессии на длинной форме — пользователь теряет заполненное.
- Проверка баннера согласия только на факт закрытия, без контроля, что скрипты действительно
  отключились.
- Игнорирование смеси старого кэша с новой версией после выкладки.

## Проверка

- Ключевые сценарии пройдены в чистом приватном окне.
- Проверено истечение сессии на форме с введёнными данными.
- Отказ от cookie проверен по факту незагрузки скриптов в панели сети.
- Проверен возврат по кнопке «Назад» после выхода из аккаунта.
- Проверено поведение после обновления версии со старым кэшем.
