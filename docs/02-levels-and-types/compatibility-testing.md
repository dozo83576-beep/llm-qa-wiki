# Тестирование совместимости

Проверка работы продукта в разных браузерах, на разных устройствах, разрешениях и версиях ОС.
Отличается от адаптивности: адаптивность — про раскладку под ширину, совместимость — про поддержку
среды в целом.

## Когда использовать

- Публичный сайт: всегда.
- Мобильное приложение: обязательно, включая старые версии ОС.
- После внедрения новой библиотеки или CSS-возможности.

## Когда не использовать

- Внутренняя система с корпоративным стандартом на один браузер — тогда матрица состоит из одной
  строки, и это фиксируется письменно.

## Матрица совместимости

Составляется до начала проверок и согласуется с заказчиком. Основание — не догадки, а данные
аналитики сайта. Нет аналитики — берём общедоступную статистику по региону и фиксируем как допущение.

Минимальная матрица для русскоязычного коммерческого сайта:

- десктоп: Chrome, Firefox, Safari, Edge — две последние версии; Yandex Browser при заметной доле;
- мобильные: Safari на iOS, Chrome на Android;
- разрешения: 360, 414, 768, 1280, 1440 px;
- ориентации: портретная и альбомная для мобильных и планшетов.

Каждая ячейка матрицы получает статус. Пустая ячейка означает «не проверено», а не «работает».

## Как это делается

- Сначала один эталонный браузер целиком — там ловятся функциональные дефекты.
- Затем остальные среды в объёме smoke плюс места, где использованы нестандартные возможности.
- Расхождение фиксируется с указанием среды: «Safari 18, iOS 17: выпадающий список не открывается
  при касании». Без среды дефект не воспроизводится.
- Эмулятор устройства в браузере — быстрый предварительный прогон, но не доказательство. Финальная
  проверка ключевых сценариев на реальном устройстве.

## Частые ошибки

- Проверка только в Chrome с выводом «кроссбраузерность в порядке».
- Отчёт о дефекте без указания браузера и версии — разработчик не воспроизведёт.
- Доверие эмулятору в вопросах шрифтов, скролла, клавиатуры и жестов: там он врёт.
- Пропуск альбомной ориентации на мобильных.

## Проверка

- Матрица зафиксирована в тест-плане и согласована.
- Каждая ячейка матрицы имеет статус: пройдено, дефект или не проверено с причиной.
- Ключевые сценарии проверены на реальном мобильном устройстве, а не только в эмуляторе.
- В каждом дефекте совместимости указаны браузер, версия, ОС и разрешение.
