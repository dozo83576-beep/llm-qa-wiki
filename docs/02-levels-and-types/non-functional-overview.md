# Нефункциональные виды: обзор

Проверка не того, что система делает, а того, насколько хорошо. Характеристики качества по
ISO/IEC 25010: производительность, совместимость, удобство, надёжность, безопасность,
сопровождаемость, переносимость.

## Когда использовать

- При составлении тест-плана: решить, какие характеристики вообще релевантны.
- Когда заказчик формулирует ожидания расплывчато: «должно быть быстро», «должно работать везде» —
  их нужно превратить в измеримые критерии.

## Когда не использовать

- Как обязательный полный набор. Проверять все семь характеристик на лендинге — трата бюджета.

## Характеристики и что из них берут на веб-заказах

| Характеристика | Что проверяется | Когда обязательно |
|---|---|---|
| Производительность | время загрузки, поведение под нагрузкой | трафик, каталог, оплата |
| Совместимость | браузеры, устройства, ОС, разрешения | всегда для публичного сайта |
| Удобство | достижимость цели, понятность | коммерческий сайт |
| Надёжность | поведение при сбое сети и сервера | формы, оплата, мобильные |
| Безопасность | доступ к чужим данным, инъекции, передача данных | личный кабинет, оплата |
| Переносимость | установка, обновление, удаление | мобильные приложения |

## Превращение ожиданий в критерии

Нефункциональное требование без числа непроверяемо. Формулировки, которые годятся в тест-план:

- не «быстро», а «главная отдаёт первый контентный кадр менее чем за 2,5 с на 4G»;
- не «работает везде», а «две последние версии Chrome, Firefox, Safari и Edge; iOS 17+ и Android 12+;
  ширины 360, 768, 1440 px»;
- не «выдерживает нагрузку», а «100 одновременных пользователей, время ответа 95-го перцентиля
  до 3 с, ошибок менее 1%».

Если заказчик не готов назвать числа — их предлагает тестировщик и фиксирует в тест-плане как
согласованное допущение.

## Частые ошибки

- Нефункциональные проверки «на глаз»: субъективная оценка скорости вместо замера.
- Проверка совместимости только в своём браузере на своём разрешении.
- Нагрузочное тестирование на проде без согласования — риск реального падения сервиса.
- Проверка безопасности без письменного разрешения владельца. Без него это не тестирование.

## Проверка

- Каждая заявленная характеристика имеет измеримый критерий в тест-плане.
- Матрица совместимости зафиксирована списком, а не словом «основные».
- Для нагрузочных и security-проверок есть письменное согласие и отдельный стенд.
