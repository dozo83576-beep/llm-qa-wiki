# Исходные чек-листы заказчика

Первоисточники, из которых выведены чек-листы вики. Хранятся неизменными: на них ссылаются как на
согласованную с заказчиком норму.

| Файл | Во что превращён |
|---|---|
| `Интерфейс пользователя - UI тестирование (чек-лист).txt` | [UI-интерфейс](../../checklists/ui-interface.md) |
| `Опыт пользователя -UX тестирование (чек-лист с описанием).pdf` | [UX-опыт](../../checklists/ux-experience.md) |
| `Функциональное тестирование (подробный чек-лист).pdf` | [Функциональный веб](../../checklists/functional-web.md) |
| `Общие проверки Интернет магазина (фунциональный и нефункциональный чек-лист).txt` | [Интернет-магазин](../../checklists/ecommerce.md) |
| `Функциональное тестирование Мобильных приложений (чек-лист).txt` | [Мобильное приложение](../../checklists/mobile-app.md) |

## Правила обращения

- Файлы не редактируются. Уточнения и дополнения вносятся в чек-листы вики, а не в исходники.
- При расхождении между исходником и чек-листом вики приоритет у исходника: он согласован с
  заказчиком.
- Ссылка на исходник указывается в разделе «Источники» каждого производного чек-листа.

## Внешние нормы, которыми дополнены исходники

Исходные материалы покрывают функциональность, UI и UX. Разделы, которых в них нет, опираются на
внешние источники:

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/) — доступность.
- [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/) — безопасность.
- [ISTQB Glossary](https://glossary.istqb.org/) — терминология и техники.
