# Управляемый baseline visual regression

Visual regression сравнивает текущий рендер с утверждённым baseline. Паттерн отвечает не за съёмку
доказательств отдельного кейса, а за безопасное принятие массовых визуальных изменений перед релизом.

## Когда использовать

- Стабильные страницы или компоненты повторно проверяются в одном browser/OS/rendering environment.
- Изменение темы, дизайн-системы или layout может затронуть несколько маршрутов.

## Когда не использовать

- Страница содержит неконтролируемые дату, рекламу, анимацию или пользовательские данные.
- Как автоматическое решение «дефект/не дефект»: pixel diff показывает изменение, но не его смысл.

## Как это делается

1. Зафиксировать browser/version, ОС, viewport, DPR, шрифты, locale, color scheme и test data.
2. Создать baseline только из прошедшего функциональную проверку кадра. Утверждение фиксирует автора,
   дату, commit/build и scope; автогенерация baseline при обычном test run запрещена.
3. Группировать diffs по общему источнику: компонент, breakpoint, тема или один expected redesign.
   Это отделяет одно системное изменение от десятков самостоятельных дефектов.
4. Просмотреть contact sheet и крупные diff-области вручную: ожидаемые изменения принять группой,
   неожиданные — оформить по затронутым пользовательским результатам.
5. Обновлять baseline отдельным reviewable change; сохранить прежнюю ревизию в VCS и повторно
   прогнать suite после approval.

Правила полноэкранной стабилизации и evidence approval не дублируются здесь: см.
[полноэкранные доказательства](fullscreen-web-screenshot-evidence.md).

## Частые ошибки

- Принять все новые snapshots одной командой без просмотра.
- Сравнивать кадры из разных ОС или browser versions и лечить шум повышением threshold.
- Маскировать крупную область, внутри которой находится проверяемый результат.

## Проверка

- Baseline имеет явный approval и воспроизводимое окружение.
- Каждый diff отнесён к ожидаемой группе либо проверен как самостоятельный риск.
- Ручной review подтверждён contact sheet; после обновления baseline повторный прогон чистый.
