# Контраст текста поверх фоновой картинки или градиента

Проверка контраста по CSS-декларациям работает, только пока фон — сплошная заливка. Если у блока
`background-image`, вычисленный `background-color` покажет `rgba(0,0,0,0)` — и любой расчёт по нему
будет выдумкой. Паттерн считает контраст по пикселям того, что реально отрисовано.

## Когда использовать

- У шапки, баннера или карточки задан `background-image`, градиент или полупрозрачная подложка.
- Текст лежит поверх фотографии, тёмной вуали или паттерна.
- Заказчик оспаривает замер, сделанный «на глаз» или пипеткой из макета, а не из живой страницы.

## Когда не использовать

- Фон — сплошной цвет, заданный CSS. Тогда достаточно двух вычисленных значений.
- Требуется полный аудит доступности: этот паттерн отвечает за один критерий (WCAG 2.2, 1.4.3), а
  не за всю проверку.

## Как это делается

1. Снять `color` текста из вычисленных стилей — цвет глифов задаётся CSS и подмены не требует.
2. Снять скриншот **области текста** по `getBoundingClientRect`.
3. Построить гистограмму цветов области. Глифы занимают меньшую часть площади, поэтому **самый
   частый цвет — это фон**.
4. Посчитать контраст по формуле WCAG: `(L1 + 0.05) / (L2 + 0.05)`, где `L` — относительная
   яркость.
5. Повторить расчёт **для каждого оттенка с долей от 3 % площади** и вынести в отчёт худший из
   них. Так вывод перестаёт зависеть от того, какой оттенок назвали «главным» — на градиенте их
   десятки.
6. Порог выбрать по кеглю: 4.5 : 1 для обычного текста, 3 : 1 для крупного — от 18.66 px либо от
   14 px при `font-weight` ≥ 700.

## Частые ошибки

- Взять `background-color` родителя и посчитать по нему: на картинке это число ничего не значит.
- Замерить один пиксель фона: на градиенте соседний даст другой результат.
- Захватить в область соседнюю иконку или подложку кнопки — доминирующим станет чужой цвет.
- Сообщить «контраст в норме», не назвав измеренное число и порог: непроверяемо.

## Проверка

В отчёте по каждому текстовому элементу стоит строка: цвет текста, измеренный цвет фона с долей
площади, полученное отношение, требуемый порог, вердикт. Например: «`rgb(252,252,252)` на
`rgb(46,52,72)` (22 % площади) → 12.03 : 1 при норме 4.5 : 1 → PASS; худший оттенок области —
11.70 : 1».
